# Security Policy

LifeCase processes sensitive personal evidence. Do not open a public issue containing receipts, invoices, addresses, account identifiers, email bodies, credentials, or exported Evidence Packs.

Report a security concern privately to the repository owner with the smallest reproducible synthetic example. Do not include live secrets or real personal documents.

The design, trust boundaries, threat scenarios, and release gates are maintained in [Security and Privacy](docs/SECURITY_AND_PRIVACY.md).
