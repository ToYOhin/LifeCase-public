## 当前产品

LifeCase 是以案件为中心的 Web 个人事务 Agent 工作台，运行形态为单用户本机 FastAPI + React/Vite + SQLite。当前交付范围是四类事务的通用闭环，保留已有保修 AI 分析范围；商业化、托管、多用户、长期真人测试和上线不列为完成门槛，打印暂缓。

四类通用路径已接通：建案/导入 → 登记与核实事实 → 回看/修正 → 登记本地行动 → 精确审批 → 完成证据 → 人工决定解决 → 历史回看。保修另有中文准备单、问题分析与报修草案。复制、下载、备注、待办完成和案件解决各有独立语义，不代替外部发送或实际处理结果。

## Agent 的实际范围

- Web 新问题 q1 只运行 `validate`（证据检索/回答），正常一次模型适配器调用，修复/重试另计。
- 无独立问题的 S1 兼容路径为 `extract → validate`。旧七阶段 Run 按原顺序读取/恢复，不改写历史。Fake Demo 是合成演示，不是生产成功替代物。
- 事实确认、修正、缺件、准备单、行动/审批和案件状态由现有领域服务处理；模型只提议。Provider 默认关闭，无外部执行工具。
