# Security and Privacy

## 数据原则

- 只处理用户明确选择的本地材料；
- 数据默认保存在用户指定的本机目录；
- 示例、测试和截图只能使用合成或不可逆脱敏内容；
- 凭据、运行数据库、导出内容和真实个人材料不得进入版本控制。

## 本地服务

应用只监听 loopback，不绑定外部网卡。浏览器通过同源 API 访问服务。数据目录拒绝卷根、程序目录、符号链接、重解析点和未经标记的已有目录，避免接管任意路径。

## 导入与解析

文件导入限制类型和大小，使用随机暂存名，并将客户端文件名仅作为有界显示元数据。解析在子进程中执行并具有硬超时；文本和 PDF 还受到页数、字节数与结构限制。当前尚未提供操作系统级 CPU、内存和网络沙箱，因此不应把未知文件视为完全可信。

## 权威与检索

对象、SourceSegment、引用和导出成员都使用 SHA-256 校验。检索必须携带 Case ID，并在 SQL 中执行 Case 过滤。返回结果会重新验证权威行和文本哈希；索引损坏或关联不完整时失败关闭。

## 模型与凭据

- Provider 默认关闭；
- 浏览器不能提交任意 endpoint、模型、工具或预算；
- API Key 仅可保存到当前 Windows 用户的 Credential Manager；
- Key 不写入 SQLite、日志、浏览器存储、模型响应或仓库；
- 分析前必须预览并确认当前 Case 范围；
- 模型输出按不可信输入处理，必须通过结构、引用和业务规则验证；
- 分析只读，不具有外部行动工具。

不同 Provider 的数据保留、训练、地域和账户控制由其各自条款决定。处理真实个人材料前，用户必须自行确认适用的数据用途、保留和组织控制。

## 导出、备份与卸载

Evidence Pack 和 Backup 使用清单与校验和验证成员。恢复操作要求干净目标并在应用前重新验证。Windows 卸载默认只移除程序和快捷方式，保留用户数据；删除数据必须由用户另行明确执行。

## 公开报告

公开 Issue、日志和截图不得包含真实材料、凭据、绝对路径、数据库内容、Provider 原始响应或私有错误详情。安全报告应使用最小合成复现。
