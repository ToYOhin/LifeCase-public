## 实际 API/Web 验收

在隔离临时数据根启动真实本地 API 与生产 Web，使用现有 Edge 153.0.4234.32。业务 API 不 mock，完成状态不通过直接写 SQLite 制造。

1. 正常创建 warranty Case，导入合成购买凭证、保修条款、故障记录。
2. UI 从含 emoji 的原文登记并确认事实；其他字段通过正常 API 登记、确认、修正或拒绝。
3. 待复核队列为空时，全量当前事实仍可进入准备单。完整字段案例另导入合成铭牌并确认序列号。
4. 明确填写诉求，检查中文预览与材料清单，使用实际系统剪贴板复制。
5. 复制失败保留可手动选择的预览；该失败检查只替换剪贴板能力，不替换业务 API。
6. 事实修正后复制先更新预览并要求再核对；冲突值不进入肯定陈述，拒绝候选后重新读取。
7. 缺件、未确认、中英文/emoji、跨案引用拒绝，以及真实 GET 延迟后切案均验证不混入旧事实。
8. 页面刷新与服务重启恢复已持久化事实/来源；本人诉求明确刷新需重填。

1440×900、1024×768、390×844 均检查相关界面与交互，无文档横向溢出；来源支持键盘展开并高亮原文。应用无控制台错误或页面异常。本次启动的验收服务已停止。

这些浏览器检查针对准备单/UI 变更；之后仅修复下面的有界检索输入问题，并重跑相关回归与综合门禁，没有重跑模型或借新测试覆盖旧失败。

## 失败记录与修复

- 新接口缺失、emoji 偏移先由失败回归证明，后实现并通过。
- 独立审查发现前端字符串等价判断与后端 NFKC/casefold 不一致：三条回归先失败，改为使用后端冲突判定后通过。
- 提交前审查发现超长混合字母数字标识符可能导致空查询：三条回归先失败；跳过单个超预算词，全部不可用时使用既有安全 fallback 后通过。
- 早期浏览器脚本曾因同 hash 导航未重新挂载、Windows 剪贴板 CRLF/LF 比较而失败。修正脚本导航与换行比较，不放宽内容或产品合同；原记录保留于本地验收资料，不将失败抹为成功。
- 五轴独立审查用于核对正确性、安全、性能、可维护性及测试；发现的上述边界问题按回归闭环处理。
