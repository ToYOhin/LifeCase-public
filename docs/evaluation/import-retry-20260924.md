## 局部修改

- 失败材料显示中文原因、处理方向及“重新选择材料”，复用原文件选择器和上传 API；明确重新导入新增记录，原材料不变。等待提取的材料也可重新读取状态。没有自动上传、重试或重新分析。
- 已保存但列表读取失败，或上传结果不确定时，只提供明确的列表核对路径，核对完成前阻止重复上传。已有同案 Source ID/hash 必须在新列表中匹配。读取与上传是不同操作，GET 恢复不会新增 Source。
