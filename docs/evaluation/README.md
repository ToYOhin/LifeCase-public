# 验证证据索引

本页按用户闭环定位已有证据，不新增验收结论。当前产品与交付状态见 [STATUS](../STATUS.md)，验证方法与历史工程门禁见 [TESTING_AND_EVALUATION](../TESTING_AND_EVALUATION.md)。每份记录只证明其日期、代码范围和样本实际覆盖的行为；不能把历史门禁或旧安装包结果移用到后来改动。

## 如何区分证据

| 标记 | 实际含义 |
|---|---|
| 实际 API/Web | 访问监听中的本地 FastAPI 与生产 Web，使用隔离合成材料；模型边界是否采用确定性传输，以对应记录为准 |
| 进程内 API + 浏览器回放 | FastAPI `TestClient` 读取真实路由，Edge 加载生产包并回放其响应；未验证浏览器到监听服务的实际 HTTP 传输 |
| 真进程重启 | 记录旧、新进程身份，使用同一隔离数据根重新读取；页面刷新或重建测试 App 不能替代 |
| 真人 / 真实模型 | 必须有独立操作者实际观察，或明确授权的指定模型运行；自动化点击、确定性传输和历史样本展示不属于该验收 |

下表中的“通过”均指链接记录当时的限定范围。失败响应注入只证明相应客户端保护，不等于真实磁盘、网络或 Provider 故障已经发生并恢复。本轮本地门禁与四类通用入口见[四类流程收口](project-completion-20261001.md)，不替代各切片的运行验收；旧提交门禁见[本地交付整理](local-delivery-20260924.md)。

当前累积源码的综合检查、行动区导航回归与交付范围见[2026-10-09 源码交付](source-delivery-20261009.md)；四类合成演示材料见[离线备料](demo-materials-20261008.md)。后端进程内检查、离线浏览器回放、GitHub CI 和真实运行仍分别记录。

- 人工处理闭环与人工案件解决均已有各自的真实进程重启证据；后者在同日后续只读补证完成，早先拒绝记录保留。两者是不同范围，不能合并为所有重启场景都通过；工具拒绝只限定对应受影响的验证。
- 各切片末尾的“下一建议”和“未授权下一步”记录当时交接。它们不是当前待办清单；例如 TXT 后的打印建议已被后续 Web 方向取代。

## 新证据的记录方式

复用现有切片记录，仅补日期、对应修改、实际检查、失败与修复、证据层级和剩余缺口。仓库内用相对链接路由到一份详细记录；本机原始产物路径用于本地复核，不作为其他贡献者可执行的环境配置。整体验证、真实服务重启、真人、模型与发布结论分别记录，不用测试数量、代码行数或文件数量替代交付结果。
