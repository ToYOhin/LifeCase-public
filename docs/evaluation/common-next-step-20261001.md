# 四类案件概览下一步提示

2026-10-01。本轮仅将已有保修概览提示复用于退款、报销、订阅取消，补齐三类事务的具体行动指引。保修 AI 范围、业务状态、审批、引用、旧值保护及历史沿用原实现。

## 实际变化

- 复用现有当前事实、材料、缺件和待办 GET，不新增 API 或写请求。概览只显示一个可执行动作及原因。
- 有待办时定位原待办，说明阻塞、失败或需核对的结果；普通沟通待办完成不代表事务已完成。没有具体待办时保留等待外部、阻塞及已关闭案件的原流程提示。
- 没有材料、文本提取未完成、事实冲突、确认依据失效或具体缺件时，进入对应材料/事实入口；不把候选值作为已确认事实。退款、订阅取消的期望结果登记进入原文事实复核，保修本人诉求入口保持原样。
- 三类材料和事实无待补项时进入已有本地行动区；不承诺外部发送、退款到账、报销到账或取消成功。复核页三类返回按钮显示“返回行动与截止”，保修仍为“返回准备单”。
- 读取保留同案、类型、状态、版本和模板校验；非保修不调用保修专用进展接口。卡片原取消、迟到响应、刷新和失败清除保护保留。

代码范围为 `App.tsx`、`features/workbench/warrantyNextStep.ts`、`WarrantyNextStepCard.tsx` 与新增 `caseNextStep.test.ts`；未新增依赖、状态或通用框架，未改后端。
