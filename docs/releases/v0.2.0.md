# LifeCase v0.2.0 Release Notes

这是原私有源仓库的历史版本说明。本公开仓库尚无 Release 或安装包；本次源码同步不创建该版本的公开资产。

`v0.2.0` 提供本地优先的个人事务工作台，以及可选的 Windows 当前用户一键安装入口。

## 主要内容

- 使用 Case 组织保修、退款、报销和订阅取消等事务；
- 本地保存导入材料、证据引用、事实复核、行动、截止日期、时间线、备份与 Evidence Pack；
- 提供受控、只读的证据分析能力，保留候选事实、引用、实际模型和版本历史；
- 模型 Provider 默认关闭，任何分析都需要明确配置、预览和确认；
- 提供 `LifeCaseSetup.exe`，为当前 Windows 用户安装自包含应用并创建快捷方式；
- 保留源码仓库中的 `scripts/lifecase.ps1` daily-use 入口。

## Windows 安装

原安装资产位于[私有源仓库 Release](https://github.com/ToYOhin/LifeCase/releases/tag/v0.2.0)，需要原仓库访问权限，不是本公开仓库下载入口：

- `LifeCaseSetup.exe`
- `SHA256SUMS.txt`

核对 SHA-256 后运行安装器。安装位置默认为 `%LOCALAPPDATA%\Programs\LifeCase`；用户数据位于 `%LOCALAPPDATA%\LifeCase`，卸载时默认保留。

安装器未进行代码签名，Windows SmartScreen 可能显示“未知发布者”。

## 源码入口

在具备 PowerShell、Python、uv、Node.js、npm 和本机锁定包缓存的源码目录中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\lifecase.ps1 setup -DataRoot "$env:LOCALAPPDATA\LifeCase"
```

## 安全边界

- 应用仅监听本机 loopback；
- Provider 默认关闭，不会自动调用模型或发现凭据；
- 分析限定在当前 Case，保持只读且不提供外部行动工具；
- API Key 只可保存到当前 Windows 用户的 Credential Manager；
- 安装包不代表托管服务、企业生产部署认证或真实个人数据的长期使用验证。
